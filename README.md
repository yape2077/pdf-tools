# PDF Toolkit (Personal Edition)

A lightweight, client-side web tool to manage, edit, and convert PDF files directly in your browser.

## Features

- **Merge PDFs:** Combine multiple PDF documents into one.
- **Split PDF:** Extract individual pages or custom ranges (e.g., `1-3,5`)[cite: 1].
- **Compress PDF:** Optimize file size using object streams[cite: 1].
- **Extract Images:** Extract images from your document as PNGs[cite: 1].
- **Rotate Pages:** Rotate PDF pages by 90°, 180°, or 270°[cite: 1].
- **Watermark:** Overlay custom diagonal watermark text[cite: 1].
- **100% Private:** Runs entirely inside your browser using JavaScript[cite: 1]. Files are never uploaded to any external server[cite: 1].
- **Dark/Light Mode:** Includes a quick theme switcher[cite: 1].
## How to Run

1. Click the green **Code** button at the top of this GitHub page.
2. Select **Download ZIP**.
3. Extract the downloaded ZIP folder on your computer.
4. Double-click `index.html` to open and run it directly in your web browser.
